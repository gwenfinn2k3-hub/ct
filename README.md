# 🎖️ TRÌNH CHIẾU TƯƠNG TÁC CAO CẤP: TRÁCH NHIỆM THỰC HIỆN NGHĨA VỤ QUÂN SỰ & THAM GIA CÔNG AN NHÂN DÂN

> **Chuyên đề môn học:** Giáo Dục Quốc Phòng & An Ninh (GDQP&AN)  
> **Dự án:** Web-based Interactive Presentation Deck (Trang trình chiếu thuyết trình web tương tác công nghệ cao)

---

## 📌 Giới Thiệu Chung
Dự án được xây dựng dưới dạng **Web Presentation Deck tương tác hiện đại** nhằm phục vụ bài báo cáo chuyên đề về *"Trách nhiệm thực hiện nghĩa vụ quân sự và nghĩa vụ tham gia Công an nhân dân của công dân và học sinh"*. 

Khác với các slide PowerPoint truyền thống, dự án áp dụng các công nghệ web tiên tiến nhất hiện nay (HTML5, CSS3, Tailwind CSS, JavaScript ES6 và Canvas API) để tạo ra trải nghiệm thuyết trình sống động, chuyên nghiệp, hỗ trợ đa nền tảng và có thể trình chiếu trực tiếp trên mọi trình duyệt web.

## 🌟 Các Tính Năng & Hiệu Ứng Công Nghệ Nổi Bật

1. **Khung Hình Trình Chiếu Chuẩn 16:9:**
   - Tự động co giãn theo tỷ lệ màn chiếu và màn hình laptop mà không bị vỡ bố cục, tránh tràn ngang hoặc mất nội dung.
2. **Hệ Thống Âm Thanh Tổng Hợp (Web Audio API Synthesizer):**
   - Tự động tạo âm thanh lướt chuyển slide kim loại (*sci-fi whoosh / click*), tiếng tap nút điều khiển và hợp âm chúc mừng (*fanfare*) mà **không cần nạp file âm thanh .mp3 bên ngoài**.
   - Có thể bật/tắt nhanh bằng phím tắt **`S`** hoặc nút loa trên thanh điều khiển.
3. **Hiệu Ứng Hạt Hào Quang Tàn Lửa (Floating Heroic Embers):**
   - Chạy trên nền Canvas độc lập với 35 hạt ánh sáng vàng kim và đỏ hào hùng bay lượn nhẹ nhàng lên cao, tượng trưng cho ngọn lửa nhiệt huyết tuổi trẻ cống hiến cho Tổ quốc.
4. **Pháo Hoa Chúc Mừng (Victory Confetti Cannon) ở Slide 10:**
   - Khi chuyển đến Slide kết luận & kêu gọi hành động, hệ thống tự động kích hoạt màn bắn pháo hoa giấy ngũ sắc và sao vàng rực rỡ kèm hợp âm chúc mừng tạo điểm nhấn cảm xúc cao trào.
5. **Hiệu Ứng Đèn Rọi Theo Chuột (Dynamic Ambient Torch):**
   - Luồng hào quang vàng kim ấm áp di chuyển mượt mà theo con trỏ chuột, chiếu sáng tinh tế các khối kính mờ (Glassmorphism).
6. **Thẻ Nghiêng 3D Từ Tính (Magnetic 3D Tilt & Specular Reflection):**
   - Các thẻ nội dung tự động nghiêng theo góc di chuột với độ sâu 3D chân thực, viền trên phản chiếu dải sáng gương mờ sang trọng.
7. **Chuyển Cảnh So Le Mượt Mà (Staggered Animation):**
   - Ứng dụng đường cong chuyển động tự nhiên (`cubic-bezier(0.16, 1, 0.3, 1)`). Tiêu đề, thẻ card và danh sách xuất hiện so le tuần tự, không gây rối mắt và đạt chuẩn 60/120fps.

## ⌨️ Bảng Phím Tắt Điều Khiển

Người thuyết trình có thể điều khiển bài giảng hoàn toàn bằng bàn phím hoặc chuột:

| Phím / Thao tác | Chức Năng |
| :--- | :--- |
| **`Phím Phải →` / `Space` / `PageDown`** | Tiến sang slide tiếp theo |
| **`Phím Trái ←` / `PageUp`** | Lùi về slide trước đó |
| **Click Nửa Trái Màn Hình** | Lùi về slide trước đó (Trang trước) |
| **Click Nửa Phải Màn Hình** | Tiến sang slide tiếp theo (Trang tiếp) |
| **`F`** | Bật / Tắt chế độ **Toàn màn hình** (Fullscreen) |
| **`M` hoặc `O`** | Mở **Mục lục dạng lưới** để chuyển nhanh đến slide bất kỳ |
| **`A`** | Bật / Tắt chế độ **Tự động trình chiếu** (7 giây / slide) |
| **`S`** | Bật / Tắt **Âm thanh hiệu ứng tương tác** |
| **`Home` / `End`** | Về ngay Slide đầu tiên / Nhảy đến Slide cuối cùng |
| **`?`** | Mở bảng tra cứu phím tắt hướng dẫn |
| **`Esc`** | Đóng cửa sổ pop-up (Mục lục hoặc Trợ giúp) |

## 🚀 Hướng Dẫn Khởi Chạy

Dự án được tối ưu tĩnh hoàn toàn (**100% Client-side**), không yêu cầu cài đặt Node.js, npm hay bất kỳ build-tool nào:

1. **Chạy Trực Tiếp:** Nhấp đúp chuột vào file `index.html` để mở ngay trên trình duyệt (Google Chrome, Microsoft Edge, Firefox, Cốc Cốc,...).
2. **Chạy Qua Live Server:** Mở thư mục dự án trong VS Code, nhấp chuột phải vào `index.html` chọn **Open with Live Server**.
3. **Triển Khai Online:** Có thể host trực tiếp miễn phí thông qua **GitHub Pages**, **Vercel** hoặc **Netlify**.
